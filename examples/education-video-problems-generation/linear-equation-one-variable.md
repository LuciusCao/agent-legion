# 一元一次方程

- 适用年级：初中一年级
- 学科：初中数学

## 核心概念

一元一次方程是只含有一个未知数，且未知数的次数都是 1 的等式，标准形式为 ax + b = 0（a ≠ 0）。解方程的依据是等式的基本性质：等式两边同时加上、减去、乘上或除以（不为零的）同一个数或式子，等式仍然成立。

解方程的一般步骤是：去分母、去括号、移项、合并同类项、系数化为 1。移项的本质是等式两边同时减去同一个式子，所以移项必须变号。

列方程解应用题是更重要的目标：审清题意，设出未知数，找出题目中的等量关系，把等量关系翻译成方程，解方程并检验答案是否符合实际意义。等量关系常来自"总量相等""路程=速度×时间""单价×数量=总价"等基本模型。

检验分两层：一是代入方程验证等式成立，二是回到题目情境判断答案是否合理（如人数不能是负数或分数）。

## 常见易错点

- 移项忘记变号，这是初一最高频错误，如由 3x = 5 - x 错得 3x - x = 5。
- 去分母时漏乘没有分母的项，或分数线充当括号的作用被忽略（分子是多项式时去分母后要加括号）。
- 去括号时括号前是负号，只给首项变号，其余项忘记变号。
- 系数化为 1 时分子分母颠倒，如 2x = 6 错得 x = 1/3。
- 列方程时设元不清（不知道 x 表示什么），或把"比……多/少""是……的几倍"等关系翻译反。
