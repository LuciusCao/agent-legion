# 简单概率

- 适用年级：小学六年级
- 学科：小学数学

## 核心概念

确定性事件分两种：必然事件（一定发生）和不可能事件（一定不发生）；不确定是否发生的事件叫随机事件。随机事件发生的可能性有大有小，可以用数来刻画。

在等可能的试验中，事件 A 的概率 = 事件 A 包含的结果数 ÷ 所有可能结果的总数。概率的取值范围是 0 到 1：必然事件概率为 1，不可能事件概率为 0，随机事件的概率介于 0 和 1 之间。

求简单概率的前提是"等可能"：摸球问题中每个球被摸到的机会相等（球除颜色外完全相同），掷骰子时每个面朝上的机会相等。判断等可能是审题第一步。

"摸出后放回"与"摸出后不放回"是两类基本模型：放回时每次试验的总数不变，不放回时总数逐次减少。列举所有可能结果（列表或画图）是避免重复与遗漏的基本功。

## 常见易错点

- 未确认等可能就直接数个数：如摸球时忽略球的大小、质地差异这一前提。
- 概率写成分数后忘记约分，或把概率写成百分数形式却不标注（两种写法都对，但要规范）。
- 混淆"可能性大"与"一定发生"：概率 0.99 的事件也可能不发生，概率 0.01 的事件也可能发生。
- 不放回模型中第二次摸球仍按原来的总数计算分母，忘记总数已经减少。
- 列举结果时出现重复或遗漏，尤其是"两枚骰子点数之和"这类组合问题中把 (2,3) 与 (3,2) 当同一种或漏算。
